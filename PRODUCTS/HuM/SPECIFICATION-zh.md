# HuM 规范（Specification）

> **文档信息**：版本 0.1（原型）｜状态：动力学仿真原型｜编制：NOHN AI
> **编制依据**：README-zh
>
> 本规范描述 **人形驱动系统（含空气动力学，HuM）** 的公开规范面：模块契约、覆盖学科与运行接口。HuM 为 Python 动力学仿真原型，融合物理学、生物力学与机械传动。

## 1. 范围与定位

### 1.1 定位

从仿生作动原语演进为闭环人形系统，横跨"感知–决策–热–可靠性–生物力学"；覆盖生物力学（Hill 肌肉）、动力学（SLIP / 弹簧-质量-阻尼）、稳定性（CoM–ZMP）、空气动力学（侧风）、热管理、可靠性工程与成本建模。

## 2. 术语与定义

| 术语 | 定义 |
|---|---|
| Hill 肌肉模型 | 力–长度 / 力–速度特性的肌肉力学模型 |
| SLIP | Spring-Loaded Inverted Pendulum，弹簧负载倒立摆步态模型 |
| CoM / CoP / ZMP | 质心 / 压力中心 / 零力矩点稳定性判据 |
| 抗倾覆裕度 | 侧风气动抗倾覆安全余量 |
| 自愈 MTBF | 含自愈机制的可靠性指标 |
| 集总-C 热模型 | 人体热预算的分块热容简化模型 |

## 3. 核心规范

### 3.1 模块契约（`hum/` 包）

| 模块 | 契约 |
|---|---|
| `bio.py` | 杠杆 / Hill 肌肉、力–长度–速度、真实 SLIP 弹簧-质量 ODE 步态 |
| `stability.py` | CoM / CoP / ZMP 与支撑多边形判据 |
| `aero.py` | 气动阻力 / 侧风侧向力 / 抗倾覆裕度 |
| `thermal.py` | 稳态 + 瞬态集总-C 人体热预算与转矩衰减 |
| `reliability.py` | 冗余可用度、自愈 MTBF、碰撞阻抗模型 |
| `cpg.py` | Hopf 振荡器网络（反相 / 步态相互耦合） |
| `fusion.py` | 卡尔曼 CoM 高度融合（IMU 控制输入 + 异步视觉） |
| `cost.py` | 参数化 TCO 分解 + 单自由度成本指数 |
| `loop.py` | 全系统报告（闭环 ZMP→CPG / 热→SLIP 耦合） |
| `plot.py` | 可视化 |

### 3.2 运行接口

- `python demo_hum.py`

### 3.3 依赖

- `requirements.txt` 管理依赖。

## 4. 一致性声明

符合本规范的实现应满足：模块契约与 §3.1 一致；默认入口可运行并输出系统报告。

## 5. 版本与变更

- 路线图：全身闭环步态生成（感知驱动的状态估计）；多模态传感器融合实现实时 CoM 跟踪；热–可靠性耦合的生命周期仿真。
- 与 DMU 同为动力学仿真原型，路线图方向相关（DMU 的 VSA / 气动耦合"与 HuM 同方向"）。

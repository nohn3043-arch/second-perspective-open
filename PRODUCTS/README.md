## 规范文档说明

每份 `SPECIFICATION-zh.md` 描述对应产品的**公开规范面**：定位与边界、接口 / 协议 / 格式、参数与配置、审计与合规、一致性声明、版本与变更。规范面向第三方离线核验，不涉及实现源码。

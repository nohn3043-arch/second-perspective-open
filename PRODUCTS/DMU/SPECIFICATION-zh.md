# DMU 规范（Specification）

> **文档信息**：版本 0.1（原型）｜状态：动力学仿真原型｜编制：NOHN AI
> **编制依据**：README-zh
>
> 本规范描述 **直驱运动统一驱动系统（DMU）** 的公开规范面：模块契约、动力学模型与运行接口。DMU 为 Python 动力学仿真原型，面向无齿轮、电磁直驱的单自由度机械作动。

## 1. 范围与定位

### 1.1 定位

覆盖级联伺服环仿真、多自由度运动学、CPG 步态生成、热预算、可靠性与成本建模的直驱运动平台；遵循"以软件换硬件、以带宽换体积、以能效换成本"原则。

### 1.2 适用场景

柔顺人形 / 四足腿部、手术机器人、精密装配、康复外骨骼、研究原型、轻载服务机器人。

## 2. 术语与定义

| 术语 | 定义 |
|---|---|
| 直驱 | 无齿轮、电磁直接驱动 |
| 级联伺服环 | 电流 → 转速 → 位置三环级联 |
| Hopf 极限环振荡器 | CPG 步态生成基础动力学 |
| m-of-n 冗余 | 可靠性冗余结构 |
| 热降额 | 绕组温升导致的转矩降额闭环 |
| 集总参数热模型 | 绕组热网络的简化建模 |

## 3. 核心规范

### 3.1 模块契约（`dmu/` 包）

| 模块 | 契约 |
|---|---|
| `dynamics.py` | 电机动力学 `T = J·alpha + B·omega + T_f`；直驱与齿轮箱对比 |
| `servo.py` | 级联电流→转速→位置伺服环；转矩饱和 + 抗积分饱和 |
| `robot.py` | 机器人本体模型 |
| `multidof.py` | 多自由度运动学 |
| `thermal.py` | 集总参数绕组热模型（瞬态 dt 感知） |
| `fusion.py` | 卡尔曼关节状态融合 + RMSE 报告 |
| `cpg.py` | Hopf 极限环振荡器网络（锁相相互耦合） |
| `reliability.py` | 元件 / m-of-n 冗余可靠性（MTBF、可用度） |
| `cost.py` | 按转矩缩放的参数化成本分解 + 单轴成本指数 |
| `system.py` | 全系统报告（含热降额闭环反馈） |
| `plot.py` | 可视化 |

### 3.2 运行接口

- `python demo_dmu.py`
- `python -m dmu.robot`

### 3.3 依赖

- `requirements.txt` 管理依赖。

## 4. 一致性声明

符合本规范的实现应满足：模块契约与 §3.1 一致；默认入口可运行并输出系统报告。

## 5. 版本与变更

- 路线图：全身多自由度动力学（DH / 牛顿–欧拉）；变刚度作动器（VSA）与气动耦合（与 HuM 同方向）。

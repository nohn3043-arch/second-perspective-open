## ✦ Quick Start

```bash
# Primary: GitHub
git clone https://github.com/nohn3043-arch/pages.git
cd pages
python serve.py 8000        # local preview → http://localhost:8000
```

## ✦ What This Page Shows

<div style="max-width:880px;margin:0 auto;padding:0 16px">

PAGES presents the NOHN AI ecosystem as six project cards behind a minimalist white-luxury visual language:

- **SPL Virtual-World Base** — virtual-world & metaverse infrastructure (`/second-reality/` live demo).
- **SPL-G1 Processor** — Trusted Compute Unit (TCU) for hardware causal audit (`/spl-g1/` showcase).
- **Anthropomorphic Agent Engine** — deterministic anthropomorphic psychology engine (`/your-soulmate/` live demo).
- **NOMOS** — auditable decision hub, IMDA AI Verify 95/100.
- **Story Engine** — long-form narrative consistency engine.
- **Antares · GFSIP** — secure cross-organization AI protocol (v1.0, implementation-ready).

Plus two feature sections:

- **SPL Cognitive Audit Engine** — a neutral, offline, decision-agnostic audit engine that runs 100% client-side in the browser (`/audit/`), no data leaves the machine.
- **AI Drawing Composition Template** — a prompt-engineering resource for consistent character rendering.

## ✦ Interactive Features

<div style="max-width:880px;margin:0 auto;padding:0 16px">

- **Bilingual** — EN/ZH blocks toggled in-page and persisted.
- **Deep Mode** — a toggle that swaps the copy to professional second-perspective causal-terminology (deterministic execution kernel, immutable invariant set, append-only ledger, SHA-256 provenance), recoloring the accent to violet.
- **Live demos & privacy pages** — companion pages: `character-studio-privacy.html`, `story-engine-privacy.html`.

</div>

## ✦ Tech & Deploy

<div style="max-width:880px;margin:0 auto;padding:0 16px">

- Pure static **HTML + CSS** — no build step, no framework.
- Self-host with `python serve.py [PORT]`, or any static server; deploys to **GitHub Pages** / **SourceForge Pages** (see `CNAME`).
- Type set in Cormorant Garamond / Noto Serif SC (serif) and Manrope / Noto Sans SC (sans), with a gold accent (`--gold:#b8954a`) defined in `:root`.

</div>

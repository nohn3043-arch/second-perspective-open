## 1. Why publish an AIMS at all

Two reasons, both load-bearing:

1. **Recomputability is the product claim.** The engine's core promise is that a third party can
   recompute the same chain root from the same input. Publishing the records — rather than asserting
   their existence — is the only way that claim is falsifiable.
2. **The gaps are more valuable than the polish.** §`OPEN-GAPS.md` lists what is *not* yet true.
   Publishing them converts an unobservable risk into an observable one, which is the precondition
   for fixing it.

## 4. How it is built (the operative mechanism)

The organisation runs its own decisions through its own engine. Each run produces a sealed record:

```
decision (real, internal)
   │
   ├─ engine.audit(decision_context)        → report + audit certificate
   │      input_digest   = SHA-256(canonical-JSON(input))
   │      report_hash    → chain event → chain_root
   │
   ├─ stored as one row in AUDIT-REGISTER.md
   │
   └─ mapped to a clause in AIMS-CLAUSE-MAP.md
```

So Clause 6.1 (risk), 8.3 (impact assessment), 9.1 (measurement) and 10 (improvement) are not
documents written once a year — they are **byproducts of running the engine on real decisions**.

Once per quarter the AIMS document set itself is fed back into the engine as a `decision_context`.
The implicit-assumption list it returns is the internal audit finding. This is recorded in
`AUDIT-REGISTER.md` with `record_type = SELF_AUDIT`.

## 5. Anonymisation rules

Published records are redacted by default:

| Field | Rule |
|---|---|
| Responsible person (`owner`) | **Code only** (`founder-01`, `eng-02`). No names, no employee IDs. |
| Customers, prospects, pricing, financials | Never published. Record carries a descriptor (`market-entry-APAC`) plus the hash, nothing else. |
| Decision content | Published as a structural descriptor. Hashes are published in full; the input text is not. |
| Engine internals | Not published here. This repository carries no implementation. |

A record whose identifier cannot be recomputed without disclosing a secret is still published —
the **hash is the evidence**, not the content.
